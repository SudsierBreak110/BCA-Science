## Median


$$\text{Median (Individual data, even)} = (\frac{n+1}{2})^{th} \ \text{observation}$$
$$\text{Median (Individual data, odd)} = (\frac{n}{2})^{th} \ \text{observation}$$



$$\text{Median (Grouped data)} = l + \frac{h}{f}(\frac{n}{2} - C)$$
$\text{where l = lower limit of median class}$
$\text{h = class width of median class}$
$\text{f = frequency of median class}$
$\text{n = total frequency}$
$\text{C = cumulative frequency of class preceding median class}$

$$\text{Mode (Grouped Data)} = l + \left(\frac{h(f_1 - f_0)}{2f_1-f_2-f_0}\right)$$

$\text{where l = lower limit of mode class}$
$\text{h = class width of mode class}$
$f_1 \text{= frequency of mode class (Maximum frequency)}$
$f_0 \text{= frequency of class preceding mode class}$
$f_2 \text{= frequency of class suceeding mode class}$
